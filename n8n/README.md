# n8n: รวบรวม Playlist ประจำวันอัตโนมัติ

workflow `playlist_collector.json` ทำงานบน **n8n Cloud**:

1. ทุกวัน **8:00–12:00** (ทุกชั่วโมง เวลาไทย) เช็ก Gmail หาอีเมลของวันนี้ที่มีไฟล์ Excel แนบ
2. คัดเฉพาะไฟล์ Playlist **11 แบบ** ที่ระบบเติมใบเช็ครูปใช้ (แยกจอ 40Blue, 40Red, 80Blue, 80Red, CITY, Spare • Signature Max • Show DC • BKJ1 • BKJ2 • Metro LED)
   ถ้าแบบเดียวกันมีหลายไฟล์ จะเลือกไฟล์ที่มาล่าสุด
3. อัปโหลดลงโฟลเดอร์ Google Drive ของวันนั้น (`Playlist_YYYY-MM-DD`) โดยไม่อัปโหลดไฟล์ที่เก็บไปแล้วซ้ำ
4. ส่งอีเมลแจ้งว่าวันนี้ได้กี่ไฟล์แล้ว (เช่น 9/11) ขาดไฟล์ไหน และมีลิงก์เปิดโฟลเดอร์
   ส่งเฉพาะรอบที่มีไฟล์ใหม่เข้ามา

**n8n ไม่ได้เติมใบเช็ครูปแทน** ส่วนนั้นยังทำใน `playlist_system.html` เหมือนเดิม n8n แค่ช่วยรวบรวมไฟล์ให้ครบในที่เดียว

## ตั้งค่าครั้งแรก

1. **สร้างโฟลเดอร์ใน Google Drive** เช่น "Playlist รายวัน" แล้วคัดลอก ID จากลิงก์
   `https://drive.google.com/drive/folders/`**`<ID ตรงนี้>`**
2. **นำเข้า workflow ใน n8n:** หน้า Overview → Create Workflow → เมนู `⋯` มุมขวาบน → **Import from File** → เลือก `playlist_collector.json`
3. **เชื่อมบัญชี:**
   - โหนด *อีเมลที่มีไฟล์ Excel วันนี้* → Credential → Create new → **Sign in with Google** ด้วยบัญชีที่รับอีเมล Playlist
   - โหนด *แจ้งเตือนทางอีเมล* → เลือก credential เดียวกัน
   - โหนด *สร้างโฟลเดอร์วันนี้* และ *อัปโหลดลง Google Drive* → สร้าง Google Drive credential → Sign in with Google
4. **เปิดโหนด "ตั้งค่า"** แก้ 3 ค่า:
   - `notifyEmail`: อีเมลที่จะรับแจ้งเตือน ใส่หลายคนได้ คั่นด้วยจุลภาค เช่น `a@company.com, b@company.com`
   - `parentFolderId`: ID โฟลเดอร์จากข้อ 1
   - `fromFilter` (ไม่บังคับ): อีเมลผู้ส่ง Playlist เช่น `a@company.com OR b@company.com` เพื่อกรองให้แม่นขึ้น
5. **ทดสอบ:** กด **Test workflow** ในวันที่มีอีเมล Playlist เข้ามาแล้ว ตรวจว่ามีโฟลเดอร์และไฟล์ใน Drive และได้อีเมลสรุป
   แล้ว **ลบโฟลเดอร์ทดสอบทิ้ง** เพราะตอนกดทดสอบเอง n8n จะไม่จำว่าอัปโหลดอะไรไปแล้ว
6. กดสวิตช์ **Active** มุมขวาบน เพื่อเปิดใช้งานจริง

## ใช้งานทุกวัน

1. รออีเมลหัวข้อ "Playlist … 11/11 ไฟล์ — ครบแล้ว"
2. เปิดลิงก์โฟลเดอร์ในอีเมล → เลือกทุกไฟล์ → ดาวน์โหลด (Drive จะรวมเป็น .zip) → แตกไฟล์
3. ลากไฟล์ทั้งหมดลง `playlist_system.html` ขั้นที่ 1 แล้วทำต่อตามปกติ

ถ้าเลย 12:00 แล้วยังไม่ครบ อีเมลจะบอกว่าขาดไฟล์ไหน ให้ตามไฟล์นั้นเอง หรือกด Test workflow อีกครั้งเมื่อไฟล์มาแล้ว

## ใช้ร่วมกันหลายคน

- **Playlist เข้ากล่องอีเมลเดียว:** รัน workflow นี้ตัวเดียวพอ แชร์โฟลเดอร์หลักใน Google Drive ให้ทีม (โฟลเดอร์ของแต่ละวันจะสร้างข้างในและได้สิทธิ์ตามไปด้วย) และใส่อีเมลทุกคนใน `notifyEmail`
- **Playlist กระจายอยู่หลายกล่องอีเมล:** แนะนำให้ตั้งที่อยู่กลาง (Google Group) หรือกฎส่งต่อให้ Playlist ทุกฉบับเข้ากล่องเดียวก่อน แล้วใช้ workflow ตัวเดียว
  ถ้ารันแยกคนละ workflow จะได้หลายโฟลเดอร์ที่ไฟล์ไม่ครบเท่ากัน

## ปรับแต่ง

- **ใช้ Outlook แทน Gmail:** เปลี่ยน 2 โหนด Gmail เป็นโหนด Microsoft Outlook (Get Many Messages แบบดาวน์โหลดไฟล์แนบ และ Send Message)
- **ชื่อไฟล์ Playlist เปลี่ยน:** แก้ `pattern` ในรายการ `kinds` ของโหนด "ตั้งค่า"
- **เปลี่ยนเวลา:** แก้ cron ในโหนด "ทุกเช้า 8:00–12:00" (ค่าเริ่มต้น `0 8-12 * * *`)
- **มีไฟล์ฉบับแก้มาทีหลัง:** ระบบจะอัปโหลดฉบับใหม่และเตือนในอีเมล ให้ลบไฟล์เก่าของแบบนั้นในโฟลเดอร์ก่อนนำไปใช้

## ข้อควรรู้

- ไฟล์ Playlist จะถูกเก็บใน Google Drive และผ่าน n8n Cloud ควรเช็กกับนโยบายข้อมูลของบริษัทก่อนใช้จริง
  (ตัว `playlist_system.html` ยังประมวลผลในเครื่องผู้ใช้เหมือนเดิม)
- n8n Cloud มีค่าบริการรายเดือนตามแพ็กเกจ workflow นี้รันวันละ 5 ครั้ง
