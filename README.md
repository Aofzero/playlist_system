# ระบบเติมใบเช็ครูปอัตโนมัติ

เครื่องมือแปลง Playlist รายวัน เป็นใบเช็ครูป (.xlsm) ของผู้ตรวจแต่ละคน
ไฟล์ HTML ไฟล์เดียว เปิดในเบราว์เซอร์ (Chrome / Edge) ได้เลย ไม่ต้องติดตั้ง ทำงานออฟไลน์
ไฟล์ทั้งหมดประมวลผลในเครื่องผู้ใช้ ไม่ถูกส่งออกไปที่ใด

**เวอร์ชัน 1.0 · 9 ต.ค. 2569**

## วิธีเปิด

- ดาวน์โหลด `playlist_system.html` แล้วดับเบิลคลิกเปิดในเบราว์เซอร์
- หรือเปิดผ่าน GitHub Pages (ถ้าเปิดใช้งานไว้) จะเข้า `index.html` แล้วพาไปที่ระบบให้เอง

## วิธีใช้ประจำวัน

1. **อัปเดต Playlist** — ถ้ามีของวันก่อนค้างอยู่ กด “ล้าง Playlist (เริ่มวันใหม่)” แล้วลากไฟล์ Playlist ของวันนั้นทั้งหมดลงกล่อง
   (สรุปรายการหนังแยกจอ 40Blue, 40Red, 80Blue, 80Red, CITY, Spare • Signature Max • Show DC • BKJ1 • BKJ2 • Metro LED)
2. **ตรวจ / แก้ไข** — ดูว่าทุกไฟล์ขึ้นวันที่เดียวกัน และไม่มีกรอบสีแดงหรือสีเหลือง
3. **เติมใบเช็ครูป** — ลากใบเช็ครูปของวันก่อนหน้าทุกไฟล์ลงกล่อง ตรวจวันที่ทำงานและรอบ (1–15 หรือ 16–สิ้นเดือน) แล้วกด “เติมใบเช็ครูป”
4. **ผลการเติม** — ดูรายการ “ควรตรวจ” ของแต่ละไฟล์ แล้วกด “ดาวน์โหลดทั้งหมด (.zip)”
   ไฟล์ที่ได้คือใบเช็คของวันนี้ และเป็นไฟล์ตั้งต้นของวันพรุ่งนี้

ในระบบมีปุ่ม **“วิธีใช้”** มุมขวาบน อธิบายขั้นตอนและกฎการจัดทั้งหมด

## กฎที่ระบบใช้จัด

- วันแรกของรอบ (วันที่ 1 และ 16) ลงหนังที่ออนอยู่ทั้งหมด หนัง # ขึ้นก่อน (ไฮไลต์เหลือง) แล้วเรียง A–Z
- วันถัดไป หนังที่ยังไม่มีในใบเช็คและสถานะ “ขึ้นใหม่” ลงใต้แถบวันที่ของวันนั้น หนังที่มีอยู่แล้วอยู่ที่เดิม ไม่ซ้ำ
- “ออกวันที่ N” ใส่เมื่อถึงวันที่หนังออก (วันที่ 1 ยังไม่ใส่) ไฟล์เดิม / ต่อสัญญา ไม่ใส่ออกวันที่และไม่เพิ่มแถวซ้ำ
- ตัวเลขที่ผู้ตรวจนับไว้ ย้ายตามชื่อหนังให้เอง
- วันที่ 16 เริ่มรอบใหม่เป็นแถบสีเขียวต่อท้ายในชีตเดิม ไม่แตะรอบ 1–15 • แถบท้ายตารางเป็นวันถัดไปเสมอ

## ข้อควรระวัง

- **ห้ามอัปโหลดไฟล์ Playlist (.xlsx) หรือใบเช็ครูป (.xlsm) ขึ้น repo นี้** เพราะมีข้อมูลแคมเปญของลูกค้า (`.gitignore` กันไว้แล้ว)
- ถ้าผลไม่ตรง เก็บไฟล์ Playlist และใบเช็คของวันนั้นไว้ส่งให้ผู้ดูแลระบบ
